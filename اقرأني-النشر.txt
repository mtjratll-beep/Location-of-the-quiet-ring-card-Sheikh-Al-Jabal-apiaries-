موقع مناحل شيخ الجبل للعسل الحضرمي دوعني — نسخة جاهزة للنشر على GitHub Pages

لماذا قد يفشل النشر؟
يجب رفع محتويات هذا الملف إلى جذر المستودع، وليس رفع ملف ZIP نفسه أو وضع الملفات داخل مجلد فرعي. يجب أن يظهر index.html مباشرة في صفحة المستودع.

خطوات النشر من الهاتف:
1) فك ضغط الملف على جهازك.
2) افتح مستودع GitHub الخاص بك.
3) اختر Add file ثم Upload files.
4) ارفع جميع الملفات الموجودة داخل هذا المجلد، بحيث يكون index.html في جذر المستودع مباشرة.
5) اضغط Commit changes.
6) افتح Settings ثم Pages.
7) في Build and deployment اختر Deploy from a branch.
8) اختر Branch: main والمجلد /(root) ثم Save.
9) انتظر اكتمال النشر وافتح الرابط الذي يعرضه GitHub Pages.

مهم:
- نافذة التثبيت تظهر باسم التطبيق وشعار MG الذي أرسلته، وبها زر «تثبيت التطبيق» وزر «تخطي الآن».
- تثبيت التطبيق يتطلب موقعًا منشورًا على HTTPS؛ المعاينة المحلية content:// لا تدعم التثبيت الحقيقي.
- Google/Firebase يحتاج إضافة نطاق GitHub Pages ضمن Firebase Authentication > Settings > Authorized domains، وتفعيل Email/Password وGoogle. يجب أن تكون قواعد Firestore مضبوطة بأمان.
- لوحة المدير موجودة في admin.html؛ لا تنشرها للعامة قبل إضافة صلاحيات مدير حقيقية إلى قاعدة البيانات وقواعد Firestore.
- GitHub Pages يستضيف ملفات ثابتة فقط ولا يشغّل خادمًا خلفيًا.


العمل مع الإنترنت الضعيف أو دون اتصال:
- أضيفت ذاكرة مؤقتة للصفحات والصور وملفات التطبيق، ويُحاول التطبيق فتح النسخة المحفوظة إذا انقطع الإنترنت بعد زيارة الموقع مرة واحدة.
- يجب نشر الموقع على HTTPS (مثل GitHub Pages) وفتحه مرة واحدة مع اتصال جيد حتى تُحفظ الملفات.
- خدمة العامل لا تعمل عند فتح index.html مباشرة من مدير الملفات باستخدام content://؛ افتح رابط الموقع المنشور.
- عند انقطاع الإنترنت قد تظهر واجهة الموقع والبطاقة المحفوظة، لكن تسجيل الدخول عبر Google/البريد ومزامنة الأختام مع Firebase وتعديل بيانات العملاء تحتاج اتصالاً بالإنترنت. لا يمكن ضمان عمل تسجيل الدخول أو المزامنة دون إنترنت.
- دعم التثبيت والعمل دون اتصال يختلف حسب المتصفح ونظام التشغيل؛ لا يمكن ضمانه في كل تطبيقات التصفح أو المتصفحات القديمة.
